# Kit de marca Foxstage / B / 1.0

Abra manual-de-marca.pdf para consultar e manual-de-marca.html ou .md para editar.

- logos/: versões horizontal, compacta, vertical e nome isolado, em SVG e PNG.
- icons/: símbolo padrão, em SVG e PNG.
- avatars/: quadrados prontos para recorte circular.
- favicons/: ICO/SVG/PNG em vários tamanhos.
- fonts/: fontes locais TTF/WOFF2 e licenças OFL.
- tokens/: cores e papéis em JSON/CSS.
- assets-index.json: inventário das artes.
- provenance.json: origem e construção.

As logos SVG são paths puros, sem fonte externa nem bitmap. PNGs de logo/símbolo possuem alpha; avatars e favicons têm fundo sólido. O nome foi tipografado em Source Sans 3 Bold e contornado a partir da opção B escolhida.

Em arquivos claros, usar um fundo escuro para visualizar. Para header estreito, usar compacta; retirar o descritor por meio da versão pronta. Não recolorir ou redesenhar durante aplicação. O site não foi alterado.
